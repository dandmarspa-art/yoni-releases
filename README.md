# Yoni releases

Installers and the update feed of Yoni, a League of Legends companion app for Windows with a native interface. Only the installers live here; the source code is private.

- Download the newest `Yoni-Setup-<version>.exe` from [Releases](../../releases/latest) and run it.
- Installed copies check this feed at startup and update themselves after you click (Settings → Updates).
- The installer is not code-signed: Windows SmartScreen shows "Unknown publisher" the first time ("More info" → "Run anyway").
